# AI Workforce local verification

Run this after pulling the AI Workforce branch locally:

```bash
npm ci
node scripts/verify-ai-workforce-local.mjs
```

The verifier runs the same local safety sequence used for the AI Workforce Command Center hardening work:

1. Patch AI Workforce UI and daemon route wiring.
2. Run AI Workforce contract checks.
3. Run the unit test suite.
4. Run the production build.

Equivalent manual commands:

```bash
npm ci
npm run ai:patch-ai-workforce-command-center
npm run check:ai-workforce-command-center
npm test
npm run build
```

Runtime files generated by AI Workforce local testing are intentionally ignored by git:

- `ai_workforce_runtime.local.json`
- `ai_workforce_operational_ledger.local.json`

The patch script is idempotent. It can be run multiple times and can upgrade older local AI Workforce daemon route patches without failing.
