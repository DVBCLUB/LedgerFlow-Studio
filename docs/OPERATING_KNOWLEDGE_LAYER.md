# Operating Knowledge Layer

LedgerFlow should grow through deeper operating knowledge before adding more screens.

This layer provides seed data for:

- multi-industry case bank
- VAS/accounting knowledge packs
- AI work order templates
- GO/HOLD/KILL/REVISIT decision templates
- product boundary statements

## Module rule

A module should stay visible only when it has:

```text
input -> processing -> output -> next decision
```

If a module is mostly static, move it into Knowledge or Labs.

## Product boundary

LedgerFlow is a company OS, R&D and simulation environment. It is not positioned as a formal accounting ERP, tax advisor, legal advisor or auditor replacement.
