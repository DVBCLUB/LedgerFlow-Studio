# Company Memory Snapshots

This folder is reserved for weekly or release-based Company Memory snapshots exported from the AgentOps Hub.

## How to create a snapshot

1. Open the app.
2. Open AgentOps Hub.
3. Go to Company Memory.
4. Click **Copy Markdown Snapshot**.
5. Paste into a new file in this folder, for example:

```text
2026-06-13-weekly-snapshot.md
```

## What to include

A useful snapshot should include:

- product boundary and guardrails;
- workboard counts;
- pending approvals;
- top ideas and Product Factory state;
- risk register;
- release readiness checklist;
- recent audit trail;
- founder decision notes.

## Guardrails

- Do not paste API keys, tokens, customer secrets, or private credentials.
- Do not treat snapshots as official accounting/legal advice.
- Keep snapshots factual and short enough for future AI agents to read quickly.
- If a snapshot mentions a risky external action, link it to an approval/audit event.
