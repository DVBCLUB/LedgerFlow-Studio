LEDGERFLOW HUB - DOC TRUOC KHI DUNG

NEU BAN CHI MUON DUNG PHAN MEM:
- DUNG TAI source code ZIP tu nut Code -> Download ZIP.
- Hay vao GitHub Actions artifact va tai goi: LedgerFlow-Hub-Windows-Download.
- Giai nen goi do, bam file .exe de mo LedgerFlow Hub.

DANG NHAP:
- Neu dung Supabase Auth: nhap email/password tren man hinh login.
- Neu dung local/offline mode: cau hinh LOCAL_ADMIN_TOKEN trong file .env.
- Chi tiet: docs/AUTH_SETUP.md

Ghi chu:
- Khong co tai khoan mac dinh trong source code.
- Supabase/GitHub/AI Gateway la cau hinh tich hop ben trong app.
- Khong chia se LOCAL_ADMIN_TOKEN, API key, token, password qua screenshot hoac log.

NEU BAN DANG CAM BO SOURCE CODE NAY VA MUON TU TAO FILE .EXE:
1. Mo Terminal tai thu muc project.
2. Chay: tools\\windows\\BUILD_WINDOWS_INSTALLER.bat
3. Cho build xong.
4. Mo thu muc release.
5. Bam file .exe de cai dat LedgerFlow Hub.
